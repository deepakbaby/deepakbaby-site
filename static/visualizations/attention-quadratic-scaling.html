Where attention’s square comes from

One query compares with every key to make one row. Repeating that for every query fills an N × N attention matrix.
One row, then N rows

N queries × N keys = N² pairwise scores

Follow the blue query as it meets every yellow key. Each magenta score completes one cell in its row; row-wise softmax turns that row into green probabilities. Then the next query repeats the same work.
