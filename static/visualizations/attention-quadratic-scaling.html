Where the square comes from

Each token becomes a query once. For each query, it compares against every token as a key. One query fills one row; all queries fill the full attention matrix.
attention scores = query tokens × key tokens = 512 × 512 = 262,144 · 12 layers × 12 heads × fp16 ≈ 75 MB
