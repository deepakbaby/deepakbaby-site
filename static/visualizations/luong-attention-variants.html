Dot

score(s_t, h_j) = s_t · h_j
Plain inner product. No learnable parameters in the scoring step itself.
params: 0
flops / pair: 2d
batches as: S @ Hᵀ (one matmul)
Matmul-friendly Same-space s, h

General

score(s_t, h_j) = s_tᵀ W_a h_j
Bilinear form. A learned projection lets s and h live in different spaces and still be compared.
params: d × d
flops / pair: 2d² + 2d
batches as: S @ (W_a Hᵀ)
Matmul-friendly More expressive

Concat

score(s, h) = v_aᵀ tanh(W_a [s; h])
A tiny MLP on the concatenation. This is the Bahdanau-style additive scoring.
params: 2d × h + h
flops / pair: ≈ 4dh + 2h
batches: elementwise tanh, no single matmul
Not a single matmul Most expressive
window 2D = 3 (half-width)
