Positional encoding: a fixed fingerprint for every position

Self-attention is order-blind, so the Transformer adds a position vector to each token. Each dimension is a sine or cosine wave; low dimensions wiggle fast, high dimensions wiggle slowly. Hover the heatmap — a column picks a dimension, a row picks a position.
Value −1 0 +1 PE(pos, 2i) = sin(pos / 10000^(2i/d))  ·  PE(pos, 2i+1) = cos(pos / 10000^(2i/d))

This token's full encoding vector — the row that gets added to its embedding. Two nearby positions share most of the slow (right-hand) dimensions and differ mostly in the fast ones, which is exactly what lets attention read off relative distance.

Intuition: it is a smooth, continuous cousin of a binary counter — the low bit (dimension 0) flips every step, higher bits flip ever more slowly, so every position gets a unique, learnable-to-read code with no extra parameters.
